# Live Monitor high-density UI — 19.0.10.60.0

- Supported grid modes: 8 / 16 / 24 columns.
- Default grid: 16 columns.
- Entry card content is intentionally limited to license plate + event time.
- Removed avatar, employee name, lane name and status badge from entry cards.
- Header is auto-hidden and leaves an 8px hover target at the top; hover/focus reveals full header and display settings.
- Increased local entry history, queue and snapshot capacity to support dense grids.
- Alerts remain available but use a compact layout.
